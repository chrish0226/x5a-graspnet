## 实机与运行版本

此前已有用户操作下的实机抓放和失败记录。松爪渐开与部分性能改动已在运行服务使用；最新方块换面及详细错误透传已写入源码并构建，发布整理时未为加载它们重启正在持物的规划/执行服务。

发布到 GitHub 是源码快照，不意味着当前运行进程已加载全部提交。需要后续在物品放稳、无在途任务时正常退出并重启，再进行实机验收。

## 待完成的验收

1. 固定场景、光照、物体和初始姿态，分别统计定位率、可规划率、夹持率和最终摆放率，记录总耗时与各阶段耗时。
2. 验证方块换面时的持物稳定性、摩擦、滑落和释放后棱角误差；白色目标离线成功样本需实机重复。
3. 完善持物附着碰撞几何和周边障碍场景，评估额外计算成本。
4. 统一解析中的物体、颜色和参照关系；比较原生抓姿和备用抓姿的实机成功率。
5. 改善标定和控制残差，再判断是否能收紧释放高度与叠放误差。

当前 8 s 搜索预算、5 mm 两指桌面容差、宽容到位和静态执行均是现场工程取舍，不能视为精度或安全认证。
